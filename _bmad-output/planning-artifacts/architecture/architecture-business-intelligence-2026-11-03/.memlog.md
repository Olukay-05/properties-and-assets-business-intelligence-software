- (decision) module set & table ownership: Tenancy/Identity, Registry (client_accounts, properties, locations, site_zones, assets, asset_custody), Inspections (templates, items, inspections, responses), Maintenance (maintenance_requests, work_orders, work_order_events, contractors), Evidence (attachments), Reporting (no tables; read-only), Audit (audit_events), Shared/Geo kernel. - (decision) RLS: app runtime connects as non-owner role without BYPASSRLS; migrations run as owner role; policies use current_setting('app.org_id', true) so unset context yields zero rows; every request/job runs inside a transaction that issues SET LOCAL app.org_id first — compatible with Neon PgBouncer transaction pooling

- (decision) client scope: memberships.client_scope = null (whole org) or a set of client_account_ids; every client-owned table carries denormalised client_account_id set by the owning service from the parent and immutable; services filter by it — prevents per-module ad-hoc join chains for client scoping
